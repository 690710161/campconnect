# CampConnect · YWC21 Buddy Finder Platform

เว็บไซต์ช่วยให้ผู้เข้าค่าย **Young Webmaster Camp #21 (YWC21)** ค้นหาและจับคู่เพื่อนร่วมค่ายตามสายที่สนใจ ทั้ง **Design, Programming, Marketing และ Content** เพื่อแลกเปลี่ยนความรู้กับเพื่อนสายเดียวกัน หรือหาเพื่อนต่างสายไว้ทำงานเป็นทีมด้วยกัน

> โปรเจกต์ MVP ของผู้สมัคร YWC21 สาย Web Programming ไม่ได้เป็นเว็บทางการของค่าย

- **Live Demo:** https://ชื่อบัญชีGitHub.github.io/campconnect/
- **Source Code:** https://github.com/ชื่อบัญชีGitHub/campconnect

## ที่มาของไอเดีย

ตอนเริ่มค่าย ผู้เข้าร่วมมักยังไม่รู้จักกัน และการหาเพื่อนตามสายหรือทักษะผ่านกลุ่มแชตทำได้ยาก โพสต์ไหลหายเร็วและไม่มีรูปแบบเดียวกันให้เปรียบเทียบ CampConnect จึงให้ทุกคนมี "การ์ดโปรไฟล์" รูปแบบเดียวกัน บอกได้ว่าตัวเองเก่งอะไร สนใจอะไร และกำลังมองหาเพื่อนแบบไหน

## ฟีเจอร์หลัก

| ฟีเจอร์ | รายละเอียด |
|---|---|
| **การ์ดโปรไฟล์** | แสดงชื่อ ชั้นปี สถานศึกษา เมเจอร์ (รองรับเมเจอร์ที่สอง) แนะนำตัว ทักษะ ความสนใจ เมเจอร์ที่มองหา และช่องทางติดต่อ |
| **ซ่อนช่องที่ไม่กรอกอัตโนมัติ** | ช่องที่ไม่บังคับ ถ้าไม่กรอกการ์ดจะไม่แสดงส่วนนั้น ไม่มีกล่องว่างหรือป้ายหัวข้อลอยๆ |
| **แท็บกรองตามเมเจอร์** | All / Design / Programming / Marketing / Content พร้อมตัวเลขจำนวนโปรไฟล์ของแต่ละสาย แต่ละเมเจอร์มีสีประจำตัว |
| **ค้นหา** | ค้นจากชื่อ ทักษะ และความสนใจ ไม่สนตัวพิมพ์เล็กใหญ่ ผลอัปเดตทันทีขณะพิมพ์ |
| **Match Quiz** | ตอบ 2 ข้อ คือ อยากเจอเพื่อนสายไหน และอยากได้เพื่อนสายเดียวกันหรือต่างสาย แล้วเว็บกรองผลให้ |
| **สมัครบัญชี 2 ขั้นตอน** | ขั้นที่ 1 ข้อมูลหลัก (บังคับเฉพาะชื่อเล่น อีเมล รหัสผ่าน เมเจอร์ และติ๊กยอมรับ) ขั้นที่ 2 ข้อมูลเพิ่มเติมที่ไม่บังคับทั้งหมด |
| **หน้าเข้าสู่ระบบ** | มีปุ่มแสดง/ซ่อนรหัสผ่าน (เดโม) |
| **Responsive** | ใช้ได้ทั้งคอมพิวเตอร์และมือถือ การ์ดปรับจาก 2 คอลัมน์เหลือ 1 คอลัมน์เมื่อจอแคบ |

## การออกแบบที่ตั้งใจ

- **ลดภาระการกรอก:** บังคับกรอกน้อยที่สุด เพราะคนที่ไม่อยากเปิดเผยข้อมูลมากก็ควรใช้งานได้ ข้อมูลที่ไม่ได้กรอกจะถูกซ่อนจากการ์ด
- **เมเจอร์ที่สอง:** เพิ่มช่องเมเจอร์ที่สอง (ไม่บังคับ) ตามกติกาที่ค่ายให้เลือกสองเมเจอร์ และไม่ให้เลือกซ้ำกับเมเจอร์แรก
- **เมเจอร์ที่มองหา:** เลือกได้หลายสาย ถ้าเลือกสายตัวเองคือหาเพื่อนสายเดียวกัน ถ้าเลือกสายอื่นคือหาเพื่อนต่างสาย ถ้าเลือกทั้งสองแบบคือเปิดรับทั้งคู่
- **ความเป็นส่วนตัว:** มีช่องติ๊กยอมรับว่าข้อมูลจะแสดงสาธารณะ และแนะนำให้ใช้ชื่อบัญชีโซเชียลแทนเบอร์โทร

## Tech Stack

- **HTML, CSS, JavaScript (Vanilla)** ไม่ใช้ framework และไม่มี build step
- **Google Fonts:** Noto Sans Thai
- **ไอคอนและอวาตาร์:** SVG ที่วาดเอง ไม่ใช้ไลบรารีภายนอก
- **Deploy:** GitHub Pages

## โครงสร้างโปรเจกต์ (แยกตามหน้าที่)

```
campconnect/
├── index.html        # โครงสร้างหน้าเว็บ (HTML) เท่านั้น
├── css/
│   └── style.css     # หน้าตา (CSS): สี เลย์เอาต์ การ์ด ป๊อปอัป responsive
├── js/
│   ├── data.js       # ข้อมูล: โปรไฟล์ของเจ้าของเว็บ (ME) + โปรไฟล์ตัวอย่าง (DEMO)
│   ├── app.js        # ตรรกะหลัก: กรอง/ค้นหา สร้างการ์ด วาดหน้าจอ แท็บ Match Quiz
│   └── auth.js       # หน้าเข้าสู่ระบบ/สมัครบัญชี 2 ขั้นตอน (เดโม)
├── images/
│   └── me.jpg        # รูปโปรไฟล์เจ้าของเว็บ (ถ้าไม่มี ระบบใช้อวาตาร์สำรอง)
└── README.md
```

| ฝั่ง | ไฟล์ | ทำเพื่ออะไร |
|---|---|---|
| โครงสร้าง (HTML) | `index.html` | กำหนดว่าหน้าเว็บมีอะไรบ้าง เช่น หัวเว็บ แท็บ ช่องค้นหา ป๊อปอัป และเรียกไฟล์อื่นมาใช้ |
| หน้าตา (CSS) | `css/style.css` | ตกแต่งสี ฟอนต์ การ์ด และปรับตามขนาดจอมือถือ |
| ข้อมูล (JavaScript) | `js/data.js` | เก็บข้อมูลโปรไฟล์ แก้ที่นี่ที่เดียวเมื่ออยากเพิ่มหรือแก้คน |
| ตรรกะ (JavaScript) | `js/app.js` | ทำให้เว็บทำงานได้ เช่น ค้นหา กรองเมเจอร์ Match Quiz |
| ตรรกะ (JavaScript) | `js/auth.js` | ฟอร์มสมัครและเข้าสู่ระบบแบบเดโม |

ลำดับการโหลดสำคัญ: `data.js` → `app.js` → `auth.js` เพราะไฟล์หลังใช้ข้อมูลและฟังก์ชันจากไฟล์ก่อนหน้า

## วิธีรันในเครื่อง

ไม่ต้องติดตั้งอะไร เปิดไฟล์ `index.html` (ต้องมีโฟลเดอร์ `css` และ `js` อยู่ข้างๆ) ด้วยเบราว์เซอร์ได้เลย หรือใช้ส่วนขยาย **Live Server** ใน VS Code

## โหมดเดโม

ฟอร์มสมัครบัญชีและเข้าสู่ระบบเป็น **หน้าตัวอย่าง** ไม่มีการส่งหรือบันทึกข้อมูลที่ไหนทั้งสิ้น

ในไฟล์ `js/auth.js` มีสวิตช์สำหรับการนำเสนอ

```js
const DEMO_SKIP_VALIDATION = true;
```

- `true` กด "ถัดไป" ข้ามขั้นที่ 1 ได้ทันทีโดยไม่ต้องกรอก ไว้โชว์เดโม
- `false` ตรวจช่องบังคับและเช็กว่ารหัสผ่านสองช่องตรงกันตามปกติ

## ข้อจำกัดในเวอร์ชันนี้

- ยังไม่มีระบบสมาชิกและฐานข้อมูลจริง ข้อมูลที่กรอกไม่ถูกบันทึก
- ยังไม่มีการอัปโหลดรูปโปรไฟล์จริง
- แท็บเมเจอร์และสีการ์ดอิงเมเจอร์แรกเท่านั้น คนที่เลือกสองเมเจอร์จะไม่แสดงในแท็บของเมเจอร์ที่สอง
- Match Quiz เป็นตัวกรองสองชั้น ยังไม่มีคะแนนความเข้ากัน
- คนที่ไม่ได้กรอกช่อง "กำลังมองหาเพื่อนสายไหน" จะไม่แสดงเมื่อเปิดตัวกรองจากแบบทดสอบ
- โปรไฟล์อื่นนอกจากเจ้าของเว็บเป็นข้อมูลสมมติเพื่อสาธิต ไม่ใช่บุคคลจริง

## แผนพัฒนาต่อ

1. เชื่อมระบบสมาชิกและฐานข้อมูลจริง (เช่น Supabase หรือ Firebase)
2. อัปโหลดรูปโปรไฟล์จริง
3. ให้ผู้ใช้แก้ไขและลบโปรไฟล์ของตัวเองได้
4. ให้คะแนนความเข้ากันจากทักษะและความสนใจ แล้วเรียงผลตามคะแนน
5. ให้ผู้ใช้เลือกซ่อนช่องทางติดต่อ และรองรับ PDPA
6. ให้โปรไฟล์ที่มีสองเมเจอร์แสดงในแท็บของทั้งสองเมเจอร์

## การใช้ AI ในการพัฒนา

โปรเจกต์นี้ใช้ AI Agent ช่วยเขียนโค้ดตามที่โจทย์ของค่ายอนุญาต โดยเจ้าของโปรเจกต์เป็นผู้กำหนดไอเดีย ฟีเจอร์ กติกา ทดสอบการใช้งาน และสั่งปรับแก้ เช่น การให้ฟอร์มกรอกน้อยที่สุด การใช้เมเจอร์ที่สอง และสวิตช์โหมดเดโม
